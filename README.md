# フォロー棚

投稿が止まっている X（Twitter）のフォローを、ブラウザの中だけで洗い出すデスクです。名簿はサーバに送りません。このブラウザの IndexedDB と控えに残ります。

誰のアカウントでも使えます。初回に、自分の X ハンドルを入れてください。

## できること

- フォロー一覧を一括で取り込む（X のページで実行する取得コード）
- フォロワー一覧と照合して、相互／一方を付ける
- 最終投稿を調べて、生存・休眠・停止を並べる
- 休眠かつ一方通行の人を外し候補にする
- 選んだ人を、X 上でまとめてフォロー解除する（解除コード）

## 使い方

1. アプリを開き、自分のハンドルを入れる（右上の設定からいつでも変更できます）
2. **取込 → Xから一括で取る**。開いた X のタブはフォロー一覧のまま、前面にして完了まで待つ。名簿のあと、同じコードが最終投稿も調べます
3. 任意でフォロワーを照合する（外し候補の精度が上がります）
4. 未確認が残れば **生存確認**（X のコード）。自動では始まりません
5. **外し候補**を見て、選んで **Xでまとめて外す**

1日のフォロー解除の目安は約 400 人です。短時間に外しすぎると X が止めます。一度に 60 人までに抑える設定があります。

## 保存

名簿はこのブラウザにだけ残ります。機種変更やキャッシュ削除で消えます。ダウンロードで JSON の控えを取ってください。取込から戻せます。書き出した JSON は Git にコミットしないでください。

## 免責

このツールは X と無関係です。取得コードと解除コードは、ログイン中の X タブで動く補助スクリプトです。X の利用規約は、自動化された収集や操作を禁じている場合があります。利用は自己責任です。アカウント制限・停止の可能性を理解したうえで使ってください。

第三者の名簿を集めたり、公開したりしないでください。
